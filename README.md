# CubCrafters Carbon Cub FX-2 for Aerofly FS 4

An aircraft package for [Aerofly FS 4](https://www.aerofly.com/) modelling the CubCrafters Carbon Cub FX-2, a two-seat tailwheel kit aircraft built in Yakima, Washington.

| | |
|---|---|
| Max takeoff mass | 846 kg |
| Wingspan | 10.9 m |
| Engine | 1 × piston, ~180 hp (132.4 kW) |
| Stall / approach / cruise | 16.1 / 24.6 / 48.7 m/s |
| Maximum airspeed | 76 m/s |
| Flaps | 4 positions (up + 3 down, up to 0.87 rad / 50°) |

## Installation

Copy this folder into your Aerofly FS 4 user aircraft directory, keeping the folder name `carboncub`:

```
Documents/Aerofly FS 4/aircraft/carboncub/
```

Restart Aerofly FS 4. The aircraft appears in the aircraft list as **Carbon Cub FX-2**.
